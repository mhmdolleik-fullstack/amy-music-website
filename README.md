# Amy Music Website

A music website I built for Amy Music, a client based in Germany.

[Visit amyymusic.com](https://amyymusic.com)

## The project

Amy sings and plays guitar at weddings, private celebrations, and corporate events. I built a German-language website where event organizers can explore her performances, learn about booking additional musicians, and get in touch with her directly.

![Performance photograph from the Amy Music website](images/hero-stage.jpg)

## From browsing to booking

- Visitors can explore the music Amy offers for different occasions, from a church ceremony to a company party.
- A photo gallery shows Amy in performance, and a dedicated band section introduces options for a larger event.
- The booking section opens an email draft with space for the event type, date, and location. Visitors can also contact Amy through Instagram.

## Built with

I used HTML, CSS, and vanilla JavaScript for the responsive, single-page site. The project includes a web app manifest, a service worker, and a sitemap.

## Run locally

From the project folder, run `python -m http.server 8000` and open [localhost:8000](http://localhost:8000).
